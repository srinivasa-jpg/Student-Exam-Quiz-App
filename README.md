# Student Exam Question Bank & Quiz App

Interactive exam-practice web app for students.

## Features
- Subject-wise question bank
- Add and delete custom MCQ questions
- Timed-style quiz workflow with configurable question count
- Instant quiz scoring
- Bookmarked questions for revision
- Quiz history and average score
- Subject performance dashboard
- Built-in starter questions
- Responsive mobile UI
- Local browser persistence
